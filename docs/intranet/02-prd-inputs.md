# 블루캣 인트라넷 PRD 작성용 입력 정리

작성일: 2026-10-29. PRD 본문이 아니라, PRD를 쓰기 위해 모아야 할 항목과 현재 아는 것·모르는 것의 목록이다.

## 1. PRD 목차 (표준)

1. 배경과 문제 정의
2. 목표와 성공 지표
3. 사용자와 역할
4. 범위 (1차 / 이후)
5. 핵심 업무 흐름
6. 데이터 모델 (무엇을 어디에 기록하나)
7. 통합 (외부 시스템)
8. 권한과 승인 규칙
9. 비기능 요구 (보안, 비용, 유지보수)
10. 일정과 단계
11. 리스크와 미결 질문

## 2. 현재 파악된 것 (이 세션에서 확인)

| 영역 | 아는 것 | 출처 |
|---|---|---|
| 회사 | 블루캣(주식회사 페즈), 칵테일 바 매장 | 저장소 README, 스킬 설명 |
| 기존 자동화 | 품의서 작성(거래처별 양식 재사용, 지메일 초안: 수신 두나, 참조 헨리·재키), 법인카드 승인내역 정리(영수증 대조, 사용내역·비고 채움, 카테고리 소계) | 사용자 스킬 설명 |

## 3. 모르는 것 — 사용자 또는 영상에서 확인

### 업무 범위
- [ ] 인트라넷이 다룰 업무 목록: 품의/지출, 거래처/발주, 재고, 인력/근무, 매출/정산, 마케팅, 고객 중 어디까지
- [ ] 월 반복 업무의 건수와 소요 시간 (품의서 몇 건, 카드내역 몇 건)
- [ ] 현재 데이터가 있는 곳: 구글 드라이브 폴더 구조(02.품의서 등), 시트, 이메일, 종이

### 사람과 권한
- [ ] 사용자(역할): 대표, 매니저, 직원, 회계 담당(두나·헨리·재키의 역할)
- [ ] 승인 규칙: 누가 무엇을 승인하나, 금액 기준이 있나

### 기술 선택
- [ ] 저장소 선택: 노션 vs 구글 시트 vs 별도 DB. 현재 구글 연동이 많으므로 시트/드라이브 기반이 유리할 수 있음
- [ ] 자동화 엔진: n8n(자체 호스팅, 무료) vs Make(구독) vs Claude 스킬·루틴(현재 사용 중)
- [ ] 에이전트 실행 위치: Claude Code 클라우드 루틴, Cowork, 로컬

### 비용과 제약
- [ ] 월 예산 상한 (도구 구독 + API 호출)
- [ ] 유료 플랜 회피 원칙 (Metricool 무료 사용 결정과 같은 기준)
- [ ] 개인정보/카드정보 보관 규칙

### 영상에서 가져올 것
- [ ] 윤자동의 ERP 모듈 구성과 데이터 모델
- [ ] 에이전트가 맡은 일과 사람이 남긴 일의 경계
- [ ] 실패 사례

## 4. 잠정 범위 제안 (검토용)

| 단계 | 모듈 | 근거 |
|---|---|---|
| 1차 | 지출·품의 (품의서 + 카드내역 + 거래처 마스터) | 이미 스킬이 있고 월 반복이 확실 |
| 1차 | 마케팅 성과 대시보드 (메타 광고 + 인스타 게시 기록) | Graph API 스크립트가 있음 |
| 2차 | 인스타 콘텐츠 파이프라인 (문구 → 이미지 → 승인 → 게시) | 사용자 최종 목표 |
| 3차 | 인력/근무, 재고 | 요구 미확인 |

## 5. 성공 지표 후보

- 품의서 1건 작성 시간 (현재 → 목표)
- 카드내역 월 마감 소요 시간
- 인스타 게시 1건 제작 시간, 주간 게시 수
- 광고 성과 리포트 자동 생성 여부 (수동 0회)
