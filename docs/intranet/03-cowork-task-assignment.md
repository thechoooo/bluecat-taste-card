## 배분 원칙
- T2, T4, T6은 서로 독립이라 동시에 진행할 수 있다.
- 돈이 나가는 결정(도구 구독, 광고 예산)은 코웍이 제안만 하고 사용자가 결정한다.
- 토큰·비밀값은 세션 간에 전달하지 않는다.

## 사용자 결정 필요
1. 코웍 세션을 지금 띄울지, PRD 입력 확인 후 띄울지
2. T2에 필요한 구글 드라이브 폴더 접근 허용 여부
3. 저장소 선택(시트/노션) 방향성
